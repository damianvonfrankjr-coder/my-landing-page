# Spectrum Killian & MB2 Dental - Landing Page

A promotional landing page for the Spectrum Killian Dental Lab Alliance and MB2 Dental partnership, offering 5 complimentary cases for new partners.

## Features

- Responsive design matching the original flyer
- Clean, professional layout
- Service comparison table
- Contact information and call-to-action
- Mobile-friendly responsive design

## Files

- `index.html` - Main HTML structure
- `style.css` - Styling and layout
- `README.md` - This file

## How to Use

Simply open `index.html` in a web browser to view the landing page.

## Design Elements

- Dark teal gradient background
- White content sections with rounded corners
- Blue and green accent colors for different centers
- Professional typography using Montserrat font
- Fully responsive for all device sizes
